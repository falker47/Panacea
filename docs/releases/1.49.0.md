# Panacea 1.49.0 candidate

This candidate retains all seven Windows maintenance sections and CustomTkinter.

- Clearer dark interface, active navigation, readable logs and useful dashboard actions.
- Responsive dashboard sampling and safer worker shutdown.
- Cleanup previews and filesystem protections; Windows commands use validated arguments.
- Turbo restores saved original settings; Resurrection reports individual results and stops when its safety prerequisite fails.
- GitHub updates require the exact Panacea.exe asset and a separate SHA-256 checksum. Interrupted or unverified downloads are never installed. Automatic replacement preserves a backup and reports failures; installations that cannot be updated safely have a manual download alternative.
- Versioned Windows binary metadata, automated fixture tests and a draft release pipeline.

No external telemetry, registry cleaner, driver updater or guaranteed performance claims are added.

## Publication gate

Publish the draft only after reviewing the candidate commit's green Windows CI, screenshots and DPI checks, safety tests, actual v1.47-to-candidate update/restart and rollback verification in an explicitly authorized disposable Windows environment, and final human approval. An unsigned build remains unsigned; no Authenticode certificate has been supplied.

After publication, verify both release assets and the stable ZEROfilez download from `/releases/latest/download/Panacea.exe` against `Panacea.exe.sha256`. Until those checks pass, the mission is not complete.
