# Panacea 2.0.0 — Next Generation

Panacea 2.0.0 is a major visual and functional update to the Windows maintenance utility. It preserves the original gold-chalice identity and redesigns all seven sections around a compact midnight-blue interface.

## Upgrade from Panacea 1.x

**A manual upgrade is recommended for existing 1.x users, especially v1.47.** The older v1.47 app can detect a newer GitHub release, but its original in-place updater has **not** been validated against V2 and does not verify a SHA-256 checksum or provide V2's protected rollback flow. Do **not** use the legacy `Install` banner to update from v1.47.

1. Close the old Panacea completely.
2. Download the official `Panacea.exe` attached to this release, or use the version-independent download link in ZEROfilez.
3. Compare its SHA-256 with `Panacea.exe.sha256` attached to the same release, and keep a backup of the previous executable.
4. Start the new executable directly. No separate installer is provided. If Windows displays an unexpected warning, do not disable its protections to proceed.

For subsequent releases, V2 includes a checksum-verified updater with protected-directory checks, readiness acknowledgement and rollback safeguards. Its in-place install path requires an appropriately protected Windows directory; portable/unprotected locations may require a **manual** update. Actual legacy-to-V2 replacement and recovery in all Windows install configurations are not yet proven by the automated suite.

## Highlights

- **New interface:** unified design and locally bundled, licensed Lucide icons across Dashboard, Cleanup, Disk, Tools, Apps, Turbo and Resurrection. Sidebar and typography are more compact, with keyboard navigation.
- **Temporary files:** optional read-only **Analyze** and independent, explicitly confirmed **Clean now**. Candidate sizes and actual deleted file bytes are distinguished; skipped reasons and diagnostics remain available.
- **Visible progress:** integrated console output expands when an operation starts, can be collapsed manually and persists across sections. External Windows utilities are identified as launch-only.
- **Resurrection:** ten visible phases, verified restore-point prerequisite, accurate completed/partial/failed/cancelled results and between-command cancellation. Deleted files are **not** restored by a Windows restore point.
- **System controls:** clearer local-drive information, improved Turbo original-state restoration, safer command timeouts, Windows Update classifications and handling of unavailable metrics.
- **Update hardening:** repository-validated HTTPS downloads, size and SHA-256 checks, safe installation paths, startup readiness and rollback controls.

## Safety and verification

This build is intended for Windows. Maintenance can permanently delete files, modify services or network settings and require administrator privileges or a restart. Read the confirmation screens and save your work. The executable is not Authenticode-signed; its SHA-256 proves byte integrity relative to the attached manifest, **not** publisher identity.

The V2 candidate passed 501 automated tests, Windows CI and packaged startup smoke checks. These do **not** establish successful real-machine execution of every privileged maintenance action, legacy in-place upgrade, interrupted install recovery or all real display-DPI modes. Those scenarios require separate Windows integration acceptance.
