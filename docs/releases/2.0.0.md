# Panacea 2.0.0 — release candidate

This candidate has not been published. Final release and merge require human approval after the remaining Windows gates.

- Redesigned all seven sections around Panacea's original gold chalice and midnight-blue palette. Professional Lucide icons are bundled locally with their license.
- Cleanup separates preview, irreversible actions and expandable output. Disk shows local fixed-drive capacity and availability. Tools and Apps provide compact, distinct action groups.
- Turbo displays observed Windows state, retained originals and an explicit restore action after partial activation. Visual effects is correctly described as a saved Windows preference.
- Resurrection shows ten actual phase states, completed/partial/failed/cancelled outcomes and expandable output. Cancellation takes effect between commands. Deletion remains irreversible; a restore point does not recover deleted files.
- Corrected native command deadlines/reaping, Unicode output, DISM restart-required results, drive inventory, multi-profile browser caches, Recycle Bin ambiguity and restore-point identity verification.
- Unverified command completion stops later sequence steps and persists a maintenance block across reopening until a newer Windows boot is verified. Storage or boot-identity failures remain explicit; closing waits for an owned operation to finish.
- Corrected unavailable metrics, non-C Windows volumes, Windows Update classification, Turbo refresh races, partial restoration, interrupted update downloads and rollback housekeeping.
- Added keyboard access to navigation, actions, drive selection and Turbo switches, and regression checks for the compact 1366×768 / 150% CTk layout.

The runtime remains Windows/Python/CustomTkinter. There is no network dependency for icons and no new runtime dependency. Windows executable metadata and checksums derive from version 2.0.0. The stable asset name remains `Panacea.exe` with `Panacea.exe.sha256`; ZEROfilez's `/releases/latest/download/Panacea.exe` integration is preserved.

Remaining gates: actual Windows DPI changes; real maintenance/Turbo/Resurrection and interruption on an explicitly authorized disposable Windows environment; prior-release elevated packaged update/restart/rollback; final human approval. Fixture tests and safe GUI/EXE smoke do not prove those operations. Do not publish the older private 1.49.0 draft as this candidate.
