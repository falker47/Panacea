# Panacea 2.0.1 — Five-section maintenance experience

Panacea 2.0.1 updates the Windows maintenance interface and improves guided cleanup while retaining the existing Windows-native maintenance engines, security restrictions, updater, and rollback controls. This release follows user acceptance of the Windows portable QA build.

## What's new

- **Five primary sections:** Overview, Space & Cleanup, Diagnostics & Repair, Performance & Startup, and Guided Maintenance. Existing tools remain available through contextual secondary navigation; use **Ctrl+1…5** to switch primary sections.
- **Clearer Overview:** a compact system summary with **Memory (RAM)**, CPU and drive metrics, Windows Update status, a read-only temporary-file analysis shortcut and a restore-point shortcut. Analysis never authorizes deletion.
- **Quick cleanup:** one explicit confirmation for a serial sequence of (1) eligible temporary files, (2) the entire Recycle Bin and (3) Windows DISM component-store cleanup. Afterwards, Panacea **opens** Windows Disk Cleanup for separate manual category selection. Opening Windows Disk Cleanup does **not** mean that its cleanup has run.
- **Less clutter in Space & Cleanup:** four individual cleanup actions remain available behind **Show individual tools**; the duplicate temporary-file analysis card was removed, while read-only analysis remains on Overview.
- **Guided Maintenance:** all ten existing Resurrection phases now show contextual explanations and actual progress/results on request, without changing the step order or the verified restore-point prerequisite.
- **Visual refinement:** clearer enlarged branding, legible Title Case sidebar navigation, consistent original Panacea iconography and compact layout for smaller/high-DPI windows.
- **Pre-release cleanup:** a small code-only refactor reduces duplicated Overview action-card layout without changing the approved user experience or maintenance behavior.

## Upgrade and download

**Recommended installed edition:** download `PanaceaSetup.exe` and `PanaceaSetup.exe.sha256`, verify the checksum, then run Setup. The protected per-machine installation supports the **user-confirmed, checksum-verified** V2 updater and rollback mechanism.

**Portable edition:** download `Panacea.exe` and `Panacea.exe.sha256`, verify the checksum and run the EXE. Portable copies from Desktop or Downloads are updated manually.

**Users of Panacea v1.47 / other V1 builds:** close the old app and install V2 manually. Do **not** use the legacy V1 in-app Install button. Setup does not silently remove existing portable V1 copies.

Permanent deletion cannot be undone through Windows restore points. Save work and review confirmation prompts. Running maintenance, modifying services or networks, or installing may require elevation/restart. The EXE and installer are **unsigned**; a matching SHA-256 checks integrity relative to the manifest, not Authenticode publisher identity. Do not disable Windows security warnings merely to install.

## Verification and remaining limits

The Windows CI validates Ruff, the complete fixture-based pytest suite, Python compilation, versioned EXE packaging, safe packaged startup, installer construction and disposable Windows integration covering isolated cleanup, protected installation, update, rollback and uninstall. The portable UX and launch were visually accepted before the version-only release preparation.

**These tests are not a guarantee of every privileged repair or destructive cleanup on a personal Windows installation.** Such operations were not exercised on the user's personal computer. The CI also cannot certify every Windows version, display configuration, or real-world interruption.
