# Panacea 2.0.2 — UX and Italian localization (QA candidate)

This candidate follows stable [v2.0.1](https://github.com/falker47/Panacea/releases/tag/v2.0.1). It is **not a published release**.

- Larger original logo and proportionally larger sidebar branding with no title overflow.
- Check updates, release actions, developer credit and current version grouped in the bottom sidebar footer.
- No hidden secondary navigation: Cleanup and Installed apps, Repair tools and Drive optimization, Performance settings and Startup apps render together in two columns, with a compact layout on constrained windows.
- Installed setup language is saved in a protected sidecar file; Italian and English affect program controls, dialogs and status labels, not just Inno Setup's wizard. Source/portable versions follow Windows UI language unless explicitly overridden for QA.
- The existing guarded backend maintenance functions, safety confirmations, updater and rollback remain unchanged.

## QA requirements

Check both setup languages on a disposable Windows installation, including uninstall, then open all five sections at normal and 150% scaling. Confirm primary actions remain visible and no label/button clipping occurs; verify no maintenance runs at startup. For protected installations, verify the chosen language remains after an EXE-only update. Do not run destructive maintenance on a personal machine solely for visual QA.

## Distribution

Do not tag or release until human feedback and green Windows CI on this exact candidate HEAD.
