# Panacea 2.0.2 — Faster Guided Maintenance and Italian interface

Panacea 2.0.2 follows [v2.0.1](https://github.com/falker47/Panacea/releases/tag/v2.0.1). It preserves the guarded Windows maintenance engine, confirmations, rollback and mandatory verified restore point while improving navigation, responsiveness, presentation and localization.

## What's new

- **Five primary sections:** Overview, Space & Cleanup, Diagnostics & Repair, Performance & Startup, and Guided Maintenance. Related tools share responsive two-column panels when width permits.
- **Faster Guided Maintenance:** the heading, warning, progress/status and start/cancel controls appear immediately; its ten numbered step cards are built cooperatively in small batches. Navigating away pauses unfinished construction, and returning resumes it.
- **Responsive ten-step timeline:** cards reflow into five, three, two or one column based on usable viewport width. Expandable explanations, actual progress, result states and full-sequence output remain available.
- **Clearer interface:** larger original branding, compact sidebar footer, improved Overview system metrics, battery/Windows Update presentation, simplified Quick cleanup, readable diagnostics controls and responsive spacing.
- **Italian and English:** installed setup-language preference is preserved during EXE updates, and UI controls, confirmation dialogs and status messages follow it.
- **Simplified title bar:** the native Windows caption displays only `Panacea 2.0.2`.

## Installation and upgrades

**Recommended installed edition:** download `PanaceaSetup.exe` and `PanaceaSetup.exe.sha256`, verify the digest and run Setup. Protected installations in Program Files can detect newer stable versions and offer a **user-confirmed**, SHA-256-verified in-app update with guarded rollback. There are no silent, unattended installations.

**Installed Panacea 2.0.0 / 2.0.1:** after v2.0.2 is published as the latest stable GitHub release, the application can detect and offer the update. If an in-app update cannot proceed, run the official Setup package manually.

**Portable edition:** download `Panacea.exe` and its matching SHA-256, close the old copy and replace it manually. Portable copies in user-writable folders are intentionally not eligible for elevated in-place replacement.

**Older V1 editions:** migrate manually using the installer; do not use the legacy V1 in-app Install button. Existing portable copies are not removed silently by Setup.

The Windows binaries are **not Authenticode-signed**; SHA-256 checks integrity relative to the published manifest, not signed publisher identity. Do not disable Windows security protections. Permanent deletion cannot be undone by a restore point.

## Verification and limits

CI covers Ruff, pytest, executable/installer packaging, non-destructive GUI smoke tests, Italian/English visual evidence at 100%/125%/150% widget scales, repeated navigation benchmarks, restricted-core measurements, and disposable Windows installer/update/rollback/uninstall tests. The performance changes were accepted in a real Windows QA session. Real compositor first-frame time on other PCs and destructive maintenance operations on the owner's machine were not verified.
