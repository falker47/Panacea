# Panacea 2.1.0 — Qt Quick desktop

Panacea 2.1.0 migrates the published CustomTkinter 2.0.2 Windows desktop to **PySide6 / Qt Quick** while preserving the original guarded Windows maintenance backend.

## What's new

- Eight original views in five navigation destinations; original chalice, midnight-blue/gold palette, English/Italian and responsive layouts.
- Persistent CPU/RAM graphs, drive metrics and Windows Update overview.
- Quick cleanup progress labels explain the current step. Black CMD-style consoles summarize repetitive file counts without hiding paths, failures, warnings or the original log.
- The Turbo master control explains five simultaneous optimizations and the restoration of saved original settings.
- Guided Maintenance shows nine visual cards while keeping the original ten backend operations and mandatory verified restore point.

## Verified updates and installation

**Installed Panacea 2.0.2:** Once the official GitHub release is published, the installed version can check for a newer release and offer a **user-confirmed**, SHA-256-verified replacement of its protected `Panacea.exe`. The same binary name, protected installation directory, Windows application identity and helper/readiness protocol remain in use. The previous executable remains recoverable until the Qt GUI verifies startup. There are no silent unattended installations.

**Portable copies:** in-place elevated updates are deliberately unavailable from user-writable folders. Close the old executable, download `Panacea.exe` and `Panacea.exe.sha256` from the official release, verify the checksum and replace the portable file manually.

**Installed v2.0.0/2.0.1 and V1:** upgrade manually using `PanaceaSetup.exe` and `PanaceaSetup.exe.sha256`. Do not use the old V1.47 unverified in-app installation control.

The installer keeps the stable Inno Setup AppId, protected Program Files path, Start Menu shortcut, language sidecar and uninstall identity. It does not touch unrelated portable copies.

## Safety and scope

The original one-use confirmations, allowlists, MaintenanceGuard, original Turbo snapshots, cancellation between phases, and protection against unknown Windows command completion remain in effect. Cleanup and Recycle Bin deletion may be irreversible; make backups before maintenance. Restore points are not backups of personal files.

The Windows binaries remain **unsigned** (no Authenticode certificate). SHA-256 verifies bytes against the separately published GitHub manifest but is not a publisher signature. Do not disable SmartScreen or antivirus.

This release must pass exact-SHA CI, Qt-native Windows binary and installer checks, protected v2.0.2→2.1.0 update and rollback tests on disposable Windows runners before publication. Hosted simulation cannot certify physical DPI, actual user-approved UAC prompts, all real repair/service scenarios or every interrupted/reboot recovery.
